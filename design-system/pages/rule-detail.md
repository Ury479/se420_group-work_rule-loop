# 规则详情 `/rules/[id]`

## 页面任务

在真实场景中使用、验证并调整一条规则。

## 结构

```text
← 规则详情                           编辑

■ 已启用 · 待观察

当准备提交重要文件，
并注意到自己正在赶时间时，
先重新打开附件确认内容和版本。

[记录一次验证]

触发场景 / 风险信号 / 禁止动作 / 最小行动

证据轨迹
✓ 7月20日  想起 · 遵守 · 结果改善
○ 7月12日  未想起 · 未遵守

来源
事件 → 复盘 → 本规则
```

## 功能

- 编辑规则字段并实时预览 RuleStatement；
- 启用、暂停、归档；
- 复制规则句；
- 查看来源事件和复盘；
- 30 秒内记录是否想起、是否遵守、是否改善；
- 展示触发、想起、遵守、改善次数；
- 三次验证后显示 EvidenceStamp；
- 有验证历史时不允许永久删除。

## Desktop

- 主区展示 RuleStatement、证据轨迹和验证入口；
- 右栏展示来源、统计定义和状态操作；
- 编辑模式保持主区单列，避免表格式后台界面。
