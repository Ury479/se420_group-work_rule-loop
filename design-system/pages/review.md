# 复盘工作台 `/events/[id]/review`

## 页面任务

把重复或高影响事件压缩为下一次可执行的最小动作。

## 结构

```text
← 复盘                           草稿已保存

来源事件
提交重要文件时选错了版本
高影响 · 学习/工作

● 风险信号
│ [最早出现了什么信号？]
│
◆ 决策点
│ [哪里本可以不同？为什么没做到？]
│
■ 最小行动
  [下次同一信号出现时，先做什么？]

可能相关的规则
[提交前重新打开附件确认]  关联

[完成复盘]
```

## 交互

- Loop Spine 同时承担进度和内容结构；
- 根因类型是辅助选项，放在决策点下方；
- 输入完成一个节点后，脊线延伸到下一节点；
- 匹配已有规则时，默认推荐关联，不自动选择；
- 无匹配时预览完整 RuleStatement，而不是六个空字段；
- 完成后进入关联规则详情；
- 已完成复盘再次进入时默认只读，可切换编辑。

## Desktop

- 主区保持单列表单；
- 右栏固定显示来源事件、准入原因和候选规则；
- 不把三个问题横向排布。
