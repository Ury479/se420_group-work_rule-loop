# 快速记录 `/record`

## 页面任务

在 60 秒内记录事实，并让用户理解为什么本次只存档或值得复盘。

## 结构

```text
← 记录刚发生的事                 已保存草稿

发生了什么？
[描述事实，不解释原因……                     ]

场景
[学习/工作] [时间] [消费] [人际] [健康] [其他]

实际影响
[低] [中] [高]
高：会造成明显损失，或很难补救

以前发生过吗？
[第一次] [曾经发生过]

更多信息（可选）⌄

──────────────────────────────────────────
[保存事件]
```

## 设计规则

- 不显示全局底部导航；
- 标题字段自动增长，避免固定三行空白；
- 影响与重复选择提供短解释，不依靠颜色；
- 可选字段折叠，默认不占首屏；
- 保存后出现 DecisionGate：
  - 普通事件：中性节点 + “已存档，这次不需要创建规则”；
  - 高价值事件：Signal Amber 菱形 + 准入原因 + “开始复盘”。

## 错误与恢复

- 返回时若有未保存内容，提供“保存草稿 / 放弃”；
- 错误说明紧邻字段；
- 保存失败保留全部输入。
