# 成长档案 `/archive`

## 页面任务

用可追溯事实回答“我是否真的做出了不同选择”。

## 结构

```text
成长档案
不是记录了多少，而是改变了多少

本周期
重复事件 2     有效规则 1     改善 3

✓ 7月20日 · 行为改善
│ 提交前想起规则，并重新确认了附件
│ 来源：提交前重新打开附件确认
│
■ 7月18日 · 规则启用
│ 21:00 后先设定结束时间
│
● 7月17日 · 普通存档
  临时会议迟到 5 分钟
```

## 设计规则

- Loop Spine 是时间线主轴；
- 普通存档、复盘、规则和验证使用不同节点形状；
- 顶部只保留重复事件、有效规则、改善次数；
- 无真实验证数据时不显示奖杯、连续天数或“有效”；
- 每个条目链接事件或规则详情；
- 筛选只提供“全部 / 事件 / 规则 / 验证”。
