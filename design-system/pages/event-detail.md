# 事件详情 `/events/[id]`

## 页面任务

解释这件事后来如何被处理，并让来源与结果可追溯。

## 结构

```text
← 事件详情                              ···

提交重要文件时选错了版本
7月18日 22:10 · 学习/工作
[高影响] [第一次]

实际后果
需要联系老师重新提交

处理轨迹
● 已记录
│
◆ 已复盘
│ 最早信号：感到赶时间
│
■ 已建立规则
│ 提交前重新打开附件确认
│
✓ 等待真实场景验证

[查看规则]
```

## 功能

- 查看全部事件事实；
- 编辑事实；
- 普通事件可升级为待复盘；
- 高价值事件开始或继续复盘；
- 展示只读复盘摘要；
- 打开关联规则；
- 删除前解释级联影响。

菜单中的编辑、删除保持次级权重，主按钮由当前状态决定。
