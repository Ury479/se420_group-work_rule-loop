# Debug 记录

以下均为本轮实际发现并修复的问题；不是对原作者意图的推断。

| 复现方式 | 问题与修复 | 回归证据 |
|---|---|---|
| 手机宽度打开首页 | 标题与状态按钮横排溢出；允许标题栏换行 | 三种视口页面检查、首页截图 |
| 手机打开记录／复盘表单 | 底部导航覆盖专注表单区域；这两个流程隐藏底部导航 | 预览截图和页面检查 |
| 本机 HTTP 注册登录 | 原 HTTPS 预览 Cookie 约束不适配 HTTP；按 BETTER_AUTH_URL 协议选择 secure Cookie | 完整注册、退出、重新登录、过期用例 |
| 使用没有 Google Fonts 网络访问权限的环境构建 | 构建必须在线拉字体；固定并本地托管 112 个字体子集与许可证 | 干净副本安装、离线字体构建成功 |
| 伪造另一个账号的父记录 id | 手工过滤不能覆盖全部关联写入；增加复合归属外键、多态触发器、强制 RLS | 59 表账号隔离、47 关联逐项拒绝测试 |
| 多步保存中途异常或返回错误 | 局部写入可能残留；以账户事务包裹完整操作，错误时回滚 | 抛异常、结构化错误回滚测试 |
| 并行首次加载偏好／目录 | 懒初始化可能重复；自然唯一键及账号级锁 | 并发初始化、重复种子与迁移测试 |
| 同时或再次提交同一事件复盘 | 重复插入会触发唯一约束异常；先在事务中检查已复盘状态，返回明确错误 | 顺序与并发重复提交测试 |
| 快速填写最小行动后立即完成复盘 | 默认关联分支尚无匹配规则时未建立新规则；默认创建，保存时明确关联或新建 | 事件→复盘→新规则→档案浏览器流程 |
| 断网保存事件、任务或其他表单 | 未捕获 Promise 及过早清空输入；捕获异常、显示错误、成功后清空、恢复按钮状态 | 拦截保存请求验证输入保留与可重试 |
| 检查清单请求失败 | 前端先前进到下一项，数据库尚未保存；保存成功后才前进 | 逐项确认并保存证据流程 |
| 记录晨间／夜间时间后刷新 | 数据已保存，但按钮状态始终从 null 初始化；读取当日日志恢复状态 | 作息刷新回归 |
| 英文模式下打开含未翻译片段的标题 | MutationObserver 对相同标题重复写入，阻塞页面；内容无变化时停止更新 | 切换英文→导航→切回中文，无运行错误 |
| 查看部分输入提示或切换英文 | 原资产部分文案包含 Unicode replacement character；恢复文案并去重词典键 | TypeScript、全页渲染与语言切换 |
| 从默认导航寻找任务、边界、娱乐等模块 | 简化导航未包含全部模块入口；设置页提供 22 个功能入口 | 设置页链接、配置保存与三种视口截图 |

修复过程中也校正了测试假设：资源／联系人保存后按原设计返回列表，关键确认的证据在 evidence 页，娱乐模块已有活动会话时需先结束或放弃，Base UI 复选框等待服务端状态更新，Next 自带的 route announcer 不应误当作业务错误提示。
