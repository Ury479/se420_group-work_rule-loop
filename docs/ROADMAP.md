## M1 — 本地核心闭环

**目标：** 个人可以使用真实数据完成“记录→判断→复盘→规则→验证→证据”。

### 2. 业务规则

- [ ] 待复盘列表按优先级排序
- [ ] 复盘草稿可恢复

## 永不作为核心的功能

| 功能 | 原因 |
|---|---|
| 通用待办和日程 | 会稀释经验转化目标 |
| 社交与公开排行榜 | 个人错误和规则具有隐私性 |
| 规则数量激励 | 会鼓励产生低质量规则 |
| 自动替用户完成复盘 | 会绕过真正需要发生的思考 |
| 复杂标签体系 | 场景与风险信号已满足检索需求 |
| 为了展示而展示的统计图 | 只保留能改变下一步行动的数据 |
