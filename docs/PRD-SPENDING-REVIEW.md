# 决策拦截台 · Hermes 支出审核

**确认日期** 2026-11-11。页面布局与冷静期流程已确认，生产代码和部署配置位于本仓库。[评审原型与截图](design/spending-review-hermes/README.md)

## 使用目标

RuleLoop 用户提交支出计划后，需要能从同一记录查看审核进度、建议和自己的最终决定。此前用户要导出 Markdown、发起外部审核并回填结果，才能继续处理一条待审记录。

## 界面与交互

- `/spending-review` 和 `/spending-review/new` 展示填报，`/spending-review/[id]` 展示同一工作区内的记录详情。桌面是填写或详情与记录两栏。手机按顺序呈现，页首有「查看审核记录」。
- 首屏收集支出名称、金额、币种、分类和用途。付款与订阅、状态、资金安全、需求、主线与工具专项放进「补充决策背景」。记录在「待处理」与「已归档」中可查。
- 表单加载完成、可以处理点击后才启用「提交审核」。
- 默认石白，通过现有「设置 → 外观」切换靛夜并跨刷新记忆。固定文案支持中英，用户填写的原文和生成建议保留生成时的语言。
- 最佳状态决策协议、主线回归、消费参照物、消费价值换算仍从侧栏辅助入口进入。记录详情保留提交信息、Markdown、复盘和旧外部审核结果。

## 审核状态

| 情况 | 行为 |
| --- | --- |
| 通过风险检查，规则无需冷静期 | 同一账户事务保存记录和一条审核任务。重复提交请求返回同一记录。 |
| 规则要求冷静期 | 记录显示结束时间，冷静期内无模型请求。结束后选「仍有需要，开始审核」才入队，也可以取消支出。 |
| 等待或审核中 | 持久任务在后台执行。离开页面后可以从记录返回，刷新后仍可查。 |
| 审核完成 | 展示建议、理由、风险、替代方案及可选的 1–168 小时冷静建议，进入「待人工确认」。规则冷静期由 RuleLoop 单独执行。 |
| 审核失败 | 显示连接失败、超时、结果未通过校验或中断，保留输入。点击重试会使用同一记录的审核快照，追加尝试次数。 |
| 人工保存 | 用户选择取消、延迟、缩减或替代、确认支出，并可填理由。决定与建议一起可回看。勾选「已在外部完成付款」只记录事实。 |

旧草稿和「待 GPT 审核」记录可以主动发起 Hermes 审核。迁移不会批量提交旧记录。旧外部审核结果和已归档决定继续可读。活动冷静期、尚无有效审核结果或已归档的记录不能通过直接请求跳过流程。

金额阈值使用现有人民币口径，美元按现有近似汇率折算。订阅分类按订阅规则处理。需要强制延期但原规则未给出时长的记录使用 30 分钟，避免显示可立即复核。夜间高风险窗口使用应用配置时区，和受保护资金限制一样由服务端阻止确认支出。

## 模型与验收

VPS 专用 Hermes 实例固定使用同机 Ollama 的 `qwen3.5:2b-vps`。模型推理使用已有 VPS 算力，无按次 API 费用。专用实例无付费回退、工具权限或共享记忆。只传本条记录审核所需的字段和规则结论，每个自由文本背景字段最多传前 320 字符。完整输入留在原记录。

Ollama 转发器要求按 JSON Schema 生成，后台进程独立校验结果。替代方案若以有效字符串列表返回，可合并展示。模型返回空列表时，已有的用户填写方案会标为「你填写的替代方案」。缺少可用替代方案或其余必填字段时，记录进入审核失败。

验收覆盖符合条件直接提交、冷静期后复核、失败重试、人工决定归档、跨账户隔离、旧记录、两套主题和中英切换。浏览器自动回归使用可控 Hermes 响应。真实 VPS 验收需要确认专用端点和本地 Qwen 实际返回有效结构，并核对实际结果在同一条记录保存。[项目架构](ARCHITECTURE.md#支出审核任务) · [部署步骤](../deploy/RUNBOOK.md#spending-review-worker-and-hermes)

### 2026-11-11 验证记录

- 本机开发库和测试库均完成 `0005` 迁移。TypeScript、ESLint、生产构建、200 项单元及数据库测试和 31 项 Chromium 回归通过。
- 浏览器使用真实 RuleLoop 后台进程、隔离 PostgreSQL 和可控 Hermes 响应，验证直接提交、冷静期复核、失败重试、最终决定、归档与重载。还覆盖石白、靛夜、旧 Markdown 入口和中英消费换算。
- 隔离环境中验证错误模型目录会在发送支出内容前被拒绝。强制停止后台进程并让租约过期后，新进程将该任务标为中断，审核调用次数保持为一次。
- 现有 Hermes 私有网页通道确认能调用同机 Qwen。首个合成回复用时 341 秒，包含无依据预算判断及无效冷静期文字。收紧提示和冷静期字段后，第二个样本明确了预算未知，但把替代方案返回为空列表。后续兼容处理保留用户提供的替代方案并标注来源。
- 最终版先回放了上述真实回复，验证原记录重试、替代方案来源标注和人工归档。随后用独立测试账号、临时数据库和现有 Hermes 私有网页隧道执行实时验收。首次请求注入 HTTP 503，重试连接真实 VPS Qwen，330 秒后返回有效建议。后台进程在同一记录保存第 2 次尝试结果，浏览器保存「缩减或替代」并重载核验。测试数据库和本机临时服务已清理。
- VPS 已完成数据库备份及 `0005` 增量迁移。专用 Hermes 在内部网络提供接口，缺少密钥时返回 HTTP 401，鉴权后只列出 `qwen3.5:2b-vps`，启用工具集为空。审核进程使用独立数据库角色。
- 上线后，使用独立合成账号从线上页面提交 39 元支出。两次 Qwen 结果分别在 106 秒和 109 秒写回原记录。浏览器保存「缩减或替代」并刷新核验，数据库同时确认审核成功和最终决定已保存。验收账号、记录和任务已清理。
