## 第二版离线原型

第二版借用项目既有 Apple 风格提案的浅色层级。工作区按习惯显示近 7 天或 14 天的打卡次数，下面以简短行呈现下一步或最近实际进度，以及记录动作。首页保留「继续手头的事」中的单个入口。[打开第二版离线原型](v2.html) · [项目视觉方向](../UI-REDESIGN-BRIEF-HOME-EVENT-AI.md)

「管理习惯」分为「正在养成」和「暂存区」。满两项时依然可以添加，新项直接进暂存区。启用暂存项时有空位就直接启用，满位就先选一项暂存，再确认交换。暂存保留打卡与下一步。改名和删除也可在这里操作，删除后过去的打卡可在最近记录回看。

## 点击顺序

1. 首页点「继续上次」，对比项目的下一步与论文最近的实际进度。
2. 点「记录开发产出」。先试空白提交，再填写产出并把下一步留空。保存后看主位是否变成刚才的产出。
3. 点「记一次阅读」，然后在 AI 和计算机网络之间切换，查看各自的阅读记录。需要接着读时，可单独写一句「这次先做什么」。
4. 用「卡在哪？」填写判断、换看的视角和验证动作。保存后看「待验证」，可以另行把验证动作设为下一步。
5. 页底展开「评审辅助 · 提醒演示与示例状态」，试「刚做完」的「去记录」，再试「隔几天」的「继续上次」。这里也能确认切换到空白起点或恢复默认示例。

提醒是评审场景。何时触发、走哪个渠道、实际能否让人回来，需要个人试用验证。
