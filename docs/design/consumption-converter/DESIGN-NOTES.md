# 消费价值换算设计说明

> 版本：v1 · 2026-07-29  
> 状态：等待视觉确认，不作为生产代码

## 视觉方向

采用 RuleLoop 已冻结的 Decision Trace，并增加一个局部签名元素：**Value Spine**。

```text
计划金额
  ↓
机会成本
  ↓
冷静期
  ↓
最终结果
  ↓
验证证据
```

Value Spine 不是新的品牌元素，而是 Loop Spine 在消费决策场景中的语义延伸。

## 三种结果层级

1. **平铺清单**：最容易理解，但与 RuleLoop 的产品语言关联较弱。
2. **价值轨迹**：推荐。能够把换算、暂停和验证表达成同一条证据链。
3. **预算台账**：数据容量最高，但容易把产品变成通用财务面板。

高保真详情采用第 2 种。

## 页面

| 页面 | 单一任务 | 主行动 |
|---|---|---|
| 输入 | 明确计划金额和比较锚点 | 查看机会成本 |
| 结果 | 理解机会成本 | 开始冷静期 |
| 冷静期 | 离开即时付款动作 | 我已经做出决定 |
| 最终结果 | 记录实际发生的事实 | 保存结果并记录验证 |
| 历史详情 | 查看决定和验证证据 | 查看关联规则 |
| 桌面详情 | 换算并启动冷静期 | 开始冷静期 |

## 隐私规则

- 首页、导航、历史列表和系统级位置默认显示“私密消费”；
- 具体敏感类别只允许在用户主动进入详情且关闭中性模式后显示；
- 页面不展示商家、地点、排名或服务说明；
- 通知只允许使用“冷静期已结束”等中性文案；
- 设计稿使用的所有金额都是本地样例，不发送给第三方。

## 开发前验收

- 用户确认 Value Spine 作为结果页方向；
- 确认默认冷静期为 2 小时；
- 确认“保护金额”是否允许出现在首页；
- 确认“智谱官方额度”的产品名称；
- 通过 375、390、768、1024、1440px 响应式评审；
- 通过键盘焦点、44px 触控目标、降动效和隐私截图评审。
