案例内容来自 2026-10-31 在用户线上账号中只读看到的 `/event-library/3`：“vibe coding 5h”。所展示的事件与复盘原文是副本；Agent 分析、适用条件、下一次场景和修订候选是人工编写的模拟响应，没有假装查到其他历史记录。只绑定本机预览，不应公开发布这份含个人记录的文件。

## 评审范围

1. 顶部工具条切换“原有界面／叠加 Agent”，用于比较保留部分与增量；工具条不是正式产品 UI。
2. 原“用 GPT 分析”按钮在原位置展开同页分析，无新主导航或学习主页。
3. 来源弹窗保留原文及证据性质；AI 推断与原始根因分开显示，未修改用户选择。
4. 编辑候选后采纳，出现在原有卡片流的行动卡；实际反馈显示为关联的复盘卡。生产实现应分别映射 `unifiedCards.cardType=action/review` 与 `linkedCardId`，不能新增平行业务行动事实表。
5. 帮助程度只是用户对本次建议的判断。若要转化为规则验证，应进入既有验证流程并满足其状态和来源约束，本原型不会自动更新规则计数。
6. “下次经验”是待确认候选；未激活或改写原规则。任意输入不被冒充为已完成智能匹配；固定下一次场景有明确标注。
7. 演示草稿和采纳结果仅保存在当前 origin 的 localStorage，刷新保留；重置只清除此原型记录。更改来源／账户时的失效检查尚不在此静态原型范围。
8. 模型不可用演示保留草稿并可退回上下文文本；没有自动重试或费用。

## 本地预览

从 RuleLoop 根目录启动本地预览：

```sh
python3 -m http.server 8788 --bind 127.0.0.1 --directory docs/design/agent-overlay
```

打开 [Agent 展开预览](http://127.0.0.1:8788/#existing-context) 可直接看到事件页内的 Agent 面板。关闭预览服务后，重新运行上面的命令即可恢复访问。需要从当前组件重新生成静态页面时，运行 `node docs/design/agent-overlay/build-preview.cjs`。

本轮仅评审中文界面的原页面增量。三语、跨事件真实检索、Hermes 接口、可靠异步任务、来源版本失效、费用和生产持久化仍以 `docs/AI-AGENT-OVERLAY.md` 为后续要求，不能用此原型的交互通过代替真实验收。
